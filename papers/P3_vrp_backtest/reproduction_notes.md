# P3 Reproduction Notes

## Environment

- Python 3.13, dependencies in the top-level `requirements.txt`.
- Reuses the Nifty option panel built by the P1 pipeline (`02_nifty_options_panel.py`);
  P3 cannot be reproduced without that panel.
- `np.random.seed(20260509)` fixed.

## Pipeline

`01_strategy_backtest.py` backtests four short-volatility strategies held to expiry, applies
the friction model, and produces net-of-cost performance and cost attribution.

## Friction model parameters

| Cost | Value |
|------|-------|
| STT (sell-side premium) | 0.05% |
| Brokerage (per leg) | 0.03% |
| Slippage (per premium) | 0.5% |
| Futures rebalancing (delta-hedged variant, per trade) | 0.01% |

## Result summary (regenerated by the pipeline)

- Every strategy is net-negative after costs.
- Put-write k = 0.94: 91.6% monthly win rate, annualised return −0.9%, Sharpe −0.37 (least
  adverse).
- Straddle variants lose ~44–45% per year.
- Cost attribution: transaction costs are secondary; tail risk is the primary loss driver.

## Known caveat (carried from source)

The `cumulative_return` column in the per-month P&L output has a floating-point overflow
from mid-2023 onward in the source implementation. No in-text figure depends on that
column, but it should be corrected before any downstream reuse of the monthly P&L file.
