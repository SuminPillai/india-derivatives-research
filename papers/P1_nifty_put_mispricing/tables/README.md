# P1 Tables

This directory holds the tables produced by the P1 pipeline. The data is **not** committed
to the repository — it is regenerated by running the scripts in the parent directory. The
structure below describes what each table contains.

| Table | Content |
|-------|---------|
| Table 2 | BS / SV / SVJ structural parameter estimates (posterior means, MoM estimates, R-hat) |
| Table 3 | Realized held-to-maturity put returns by moneyness bucket (k = 0.94–1.00) |
| Table 4 | Realized delta-neutral strategy returns (ATM straddle, crash-neutral spread) and Sharpe ratios |
| Table 5 | Finite-sample p-values, baseline simulation, per model and bucket |
| Table 6 | Finite-sample p-values under jump-risk adjustment |
| Table 7 | Finite-sample p-values under estimation-risk adjustment |
| Table 8 | Regime sub-period p-values (pre-2018 / NBFC / COVID / inflation) |

Column conventions follow Pillai (2012) for continuity with the cited prior work.
