# Reproducibility Guide

This document describes the end-to-end pipeline for reproducing the empirical results
in the working papers distributed in this repository. The repository contains **code, not
data** — all data must be re-pulled from the original sources documented in
`data_sources.md`.

## Environment

- Python 3.13
- Install dependencies: `pip install -r requirements.txt`
- A local MongoDB instance (default `mongodb://localhost:27017/`) is used as the
  intermediate store for equity, futures, options, and macro series. Override the
  connection string via the `MONGO_URI` environment variable where scripts support it.
- DefinEdge API access (subscription) is required only for the equity/F&O OHLC pulls;
  NSE bhavcopy, Yahoo Finance, and RBI series are free.

## Reproducibility seed

All simulation and resampling scripts set `np.random.seed(20260509)`. Any deviation from
this seed produces non-matching numerical results. The seed value is fixed in each
script's `main()`; do not change it if you intend to reproduce the published tables.

## Pipeline overview

| Paper | Stage | Script | Produces |
|-------|-------|--------|----------|
| P1 | Spot + risk-free | `00_nifty_spot_and_tbill.py` | Nifty 50 daily spot, 91-day T-bill series |
| P1 | Options ingest | `01_bhavcopy_downloader.py` | Parsed NSE F&O bhavcopy records |
| P1 | Panel build | `02_nifty_options_panel.py` | Held-to-maturity monthly put panel (k = 0.94–1.00) |
| P1 | Estimation | `03_mcmc_estimation.py` | BS / SV (MCMC) / SVJ (MoM) structural parameters |
| P1 | Simulation | `04_option_simulation.py` | 25,000-path finite-sample p-values |
| P1 | Regime split | `05_regime_split.py` | Sub-period (pre-2018 / NBFC / COVID / inflation) results |
| P2 | Backtest | `01_run_strategies.py` | Per-strategy alpha and Sharpe; Romano–Wolf StepM survivors |
| P3 | Backtest | `01_strategy_backtest.py` | VRP strategy P&L net of STT / brokerage / slippage |

Run the numbered scripts in order within each paper directory. Each paper's
`reproduction_notes.md` documents the exact inputs, expected outputs, and any manual
steps.

## Data flow

```
original sources ──> local pull scripts ──> MongoDB (pricedatabase / optionsdatabase)
                                                   │
                                                   ▼
                                        analysis scripts ──> tables/
```

The `tables/` directories in this repository contain structure descriptions, not the
table data itself — the data is regenerated by running the pipeline.
